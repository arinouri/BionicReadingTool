About Read Easier

Read Easier is a collection of small, free tools built for neurodiverse readers, students with ADHD, dyslexia, or anyone who wants text to feel less overwhelming.

• 100% client-side (no data collection)
• Works in any modern browser
• Open-source on GitHub
